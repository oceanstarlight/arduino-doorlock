01전원 넣기 전 안전 점검

USB를 꽂기 전에 하나씩 체크해. 체크 상태는 이 브라우저에만 저장돼.

보드나 모듈이 망가질 수 있는 실수 3가지
  • RC522 VCC를 5V에 꽂기. 반드시 3.3V 핀에 꽂아.
  • 서보 전원을 아두이노 5V에서 끌어오기. 서보가 움직일 때 전류가 튀어서 보드가 리셋되거나 USB 포트가 위험해져. 외부 5V를 쓰고 GND만 공통으로 묶어.
  • 두 보드의 5V 핀끼리 연결하기. 각 보드는 자기 USB로 전원을 받고, 보드끼리는 GND와 신호선 2개만 연결해.

02보드 A · 입력부

키패드 8선, RC522 7선(분압 포함), LCD 4선, 보드 B 링크 3선. 점(●)이 찍힌 곳만 연결된 거고, 점 없이 겹친 선은 지나가는 거야.

5V3.3VGND신호연결점
RC522 분압 (신호선 4개: SDA·SCK·MOSI·RST)

아두이노 핀 → 1kΩ → RC522 핀, 그리고 RC522 핀 쪽 노드에서 2kΩ → GND. 5V × 2/3 ≈ 3.3V가 돼. 2kΩ이 없으면 2.2kΩ 하나, 또는 1kΩ 두 개를 직렬로 써도 돼. MISO는 RC522가 내보내는 신호라 분압 없이 직결해. IRQ는 연결 안 해.

모듈 핀아두이노 A선 색(추천)메모
키패드 핀 순서 확인

대부분의 4x4 멤브레인 키패드는 앞면 기준 왼쪽부터 R1 R2 R3 R4 C1 C2 C3 C4야. 제품마다 다를 수 있으니, 업로드 후 키를 눌러 LCD에 *가 찍히는지 확인해. 숫자가 엉뚱하게 나오면 코드의 rowPins, colPins 순서만 바꾸면 돼. 키패드는 전원이 필요 없어서 순서가 틀려도 고장 나지 않아.

03보드 B · 문 작동부

위쪽 가로줄 2개는 브레드보드 전원 레일이야. 위가 GND(−), 아래가 아두이노 5V(+). 서보는 이 레일이 아니라 아래쪽 외부전원에 연결해.

5VGND신호연결점
HC-06 RXD는 3.3V 신호

보드 B D1(TX) → 1kΩ → HC-06 RXD, RXD 쪽 노드에서 2kΩ → GND. HC-06 TXD(3.3V 출력)는 D0에 직결해도 돼. HC-06 VCC는 5V(모듈 안에 레귤레이터 있음). 핀 이름은 제품마다 순서가 다르니 모듈 뒷면 글씨를 보고 꽂아.

서보 전원

5V 1A 이상 어댑터나 브레드보드 전원모듈(점퍼를 5V로)을 써. 새 AA 건전지 4개는 약 6.4V라 SG90 정격(4.8~6V)을 살짝 넘어서 비추천이야. 전원 +/− 사이에 470µF 전해 커패시터를 꽂아(긴 다리 +, 띠 표시 쪽 −). 외부전원 GND는 반드시 아두이노 GND와 연결해. 이게 빠지면 서보가 신호를 못 알아들어.

모듈 핀아두이노 B선 색(추천)메모

04보드 A ↔ 보드 B 연결

UART는 TX와 RX를 서로 엇갈려서 연결해. GND를 꼭 같이 연결해야 신호 기준 전압이 맞아.

05조립 & 테스트 순서

한 번에 다 꽂지 말고, 모듈 하나 연결 → 확인 → 다음 순서로 가. 문제가 생기면 방금 꽂은 모듈만 보면 돼.

  1. 라이브러리 설치

    Arduino IDE 라이브러리 매니저에서 Keypad(Mark Stanley), MFRC522, LiquidCrystal I2C(Frank de Brabander), MsTimer2를 설치해. Servo, SoftwareSerial은 기본 내장이야.

  2. 보드 A: LCD만 연결 → I2C 주소 찾기

    firmware/tools/i2c_scanner 업로드 후 시리얼 모니터(9600)에서 주소를 확인해. 보통 0x27이나 0x3F. 다르면 LCD_ADDR를 고쳐.

    통과: 주소가 1개 출력됨. 글자가 안 보이면 LCD 뒷면 파란 가변저항을 드라이버로 돌려.

  3. 보드 A: 키패드 추가

    board_A_input 업로드. 숫자를 누를 때마다 LCD 2번째 줄에 *가 늘어나는지 확인. 1234# → ACCESS GRANTED.

    통과: *로 지워지고, 틀린 번호 3번이면 30초 차단.

  4. 보드 A: RC522 추가 (분압 저항 포함)

    USB를 뽑은 상태에서 연결하고, VCC가 3.3V인지 한 번 더 확인해. 카드를 대면 시리얼 모니터에 RFID UID: XX XX XX XX가 떠. 이 값을 코드의 ALLOWED_UID에 적고 다시 업로드해.

    통과: 등록 카드 → GRANTED, 미등록 카드 → DENIED + UID 표시.

  5. 보드 B: LED + 버튼

    HC-06는 아직 꽂지 말고 board_B_door 업로드. 빨강 LED가 켜져 있어야 해. 버튼을 누르면 초록이 5초 켜졌다가 다시 빨강.

    통과: 버튼을 한 번 누르면 한 번만 열림(채터링 없음).

  6. 보드 B: 서보 + 외부전원

    외부전원 → 커패시터 → 서보 순서로 꽂고, 외부전원 GND를 아두이노 GND에 연결. 버튼으로 0° ↔ 90°가 움직이는지 봐. 걸쇠에 달기 전에 각도를 확인하고 LOCK_ANGLE, UNLOCK_ANGLE을 조정해.

    통과: 움직일 때 보드가 리셋되지 않음(LED가 꺼졌다 켜지지 않음).

  7. 보드 B: HC-SR04

    VCC 5V, GND, Trig D6, Echo D7. 초음파는 폰 인증 후에만 측정하니까 다음 단계에서 같이 확인해.

  8. 보드 B: HC-06 (분압 저항 포함)

    업로드가 끝난 뒤에 HC-06를 꽂아. 폰에서 HC-06 페어링(PIN 기본값 1234 또는 0000) → Serial Bluetooth Terminal 앱에서 연결 → BT1234 전송.

    통과: 폰에 ARM 표시 + 노랑 LED 깜빡 → 센서 앞 1m 안으로 손을 넣으면 열림.

  9. 보드 A ↔ B 연결

    A2→D4, A1←D5, GND–GND. 키패드로 열면 B의 서보가 움직이고, 버튼으로 열면 A의 LCD에 OPEN from INSIDE button이 떠야 해.

    통과: 4가지 방법(키패드·RFID·폰·버튼) 모두 열리고 5초 뒤 자동 잠김.

폰 앱 설정 (Serial Bluetooth Terminal)

  • Devices 탭 → HC-06 선택 → 연결
  • Settings → Send → Newline: CR+LF 또는 LF
  • BT1234 보내면 인증, LOCK 보내면 즉시 잠금
  • 비밀번호 3번 틀리면 30초간 무시됨

1m 판정의 한계 (발표 때 설명용)

HC-06은 신호 세기(RSSI)를 아두이노에 알려주지 않아. 그래서 블루투스로 누구인지 인증하고, 초음파로 얼마나 가까운지를 재는 2단계 방식을 썼어. 초음파는 폰이 아니라 앞에 있는 물체를 재기 때문에, 인증 후 30초 안에만 측정하고 3번 연속 100cm 이내일 때만 열어서 오작동을 줄였어.

07업로드할 때 주의

보드 B에 업로드하기 전: D0에 꽂힌 선(HC-06 TXD) 뽑기

D0·D1은 USB 업로드에도 쓰는 핀이야. HC-06이 D0을 잡고 있으면 avrdude: stk500_recv(): programmer is not responding 같은 오류가 나. 보드가 고장 나는 건 아니고, 선만 뽑고 다시 업로드하면 돼.

보드 A는 그냥 업로드해도 돼

보드 A는 링크에 SoftwareSerial(A1·A2)을 써서 D0·D1이 비어 있어. 시리얼 모니터로 RFID UID 확인도 가능해.
