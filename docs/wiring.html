01부품과 저항 사용 계획

새로 살 것 없이 지금 가진 저항(2kΩ 6개, 10kΩ 5개, 220Ω 10개)만으로 만들었어. 분압은 모두 "위(핀 쪽) 1 : 아래(GND 쪽) 2" 비율이라 출력이 약 3.33V야. 1kΩ이 없어서, 아래쪽을 같은 저항 2개(또는 4개)를 직렬로 이어 2배를 만들었어.

용도보드위 (핀 쪽)아래 (GND 쪽, 직렬)2kΩ10kΩ220Ω
RC522 SCK 분압A2kΩ2kΩ + 2kΩ300
RC522 MOSI 분압A2kΩ2kΩ + 2kΩ300
RC522 SDA(SS) 분압A10kΩ10kΩ + 10kΩ030
HC-06 RXD 분압B220Ω + 220Ω220Ω × 4006
LED 3개B각 220Ω003
합계 / 보유RC522 RST는 저항 없이 3.3V 직결6 / 63 / 59 / 10
왜 채널마다 저항이 다르냐면
  • SCK·MOSI는 1초에 4백만 번 바뀌는 빠른 신호라 작은 저항(2kΩ)이 필요해. 10kΩ으로 만들면 신호가 제때 못 올라가서 통신이 깨져.
  • SDA(SS)는 통신 시작·끝에만 바뀌는 느린 신호라 10kΩ으로 만들어도 돼. 2kΩ이 6개뿐이라 두 채널(SCK·MOSI)에 먼저 썼어.
  • HC-06 RXD는 남은 게 220Ω뿐이라, 작은 저항을 6개 이어서 같은 1:2 비율(440Ω : 880Ω)을 만들었어.

저항 색띠로 구별하기

금색 띠(오차)가 오른쪽에 오게 놓고 왼쪽부터 읽어. 220Ω(빨강 빨강 갈색)과 2kΩ(빨강 검정 빨강)은 색이 비슷하니까, 헷갈리면 멀티미터 저항 모드로 재 보고 꽂아.

그 밖의 부품

  • Arduino UNO R3 2개, 400홀 하프 브레드보드 2개
  • 4x4 키패드, RC522 + 카드, 1602 LCD(I2C), HC-06, HC-SR04, SG90
  • LED 빨강·노랑·초록, 4핀 택트 버튼, 470µF 전해 커패시터
  • 서보용 5V 외부전원 (1A 이상 어댑터 또는 브레드보드 전원모듈)
  • 점퍼선 수-수(M-M), 암-수(F-M) 넉넉히

02전원 넣기 전 안전 점검

보드나 모듈이 망가질 수 있는 실수
  • RC522 3.3V 핀을 5V에 꽂기. RC522는 3.3V 전용이야.
  • 보드 B 브레드보드의 위쪽 + 레일(아두이노 5V)과 아래쪽 + 레일(서보 외부 5V)을 잇기. 두 전원이 맞붙어.
  • 서보 빨강선을 아두이노 5V에 꽂기. 서보가 움직일 때 전류가 튀어서 보드가 리셋되거나 USB 포트가 위험해져.
  • 두 보드의 5V 핀끼리 연결하기. 보드끼리는 GND와 신호선 2개만 연결해.
  • 470µF 커패시터 극성을 반대로 꽂기. 띠(−) 쪽 다리를 − 레일에 꽂아.

03분압 회로 자세히

아두이노 핀은 5V를 내보내는데, RC522 신호선과 HC-06 RXD는 3.3V까지만 받아. 그래서 "위 1 : 아래 2" 비율의 저항으로 전압을 낮춰. 그림은 SCK 채널(2kΩ 3개) 예시야. SDA는 같은 자리에 10kΩ 3개를 꽂으면 되고, HC-06은 220Ω 6개라 모양이 조금 길어(보드 B 6단계 참고).

  • ① 아두이노 핀에서 온 선을 P칸(e줄)에 꽂아.
  • ② 위 저항을 P칸 c줄 → N칸 c줄(3칸 옆)에 눕혀서 꽂아.
  • ③ 아래 저항 1을 N칸 b줄 → X칸 b줄(또 3칸 옆)에 눕혀서 꽂아.
  • ④ 아래 저항 2의 한쪽 다리를 X칸 a줄에, 다른 다리를 − 레일(GND)에 꽂아. 여기서 − 레일은 파란 줄과 − 표시가 있고, 1단계에서 우노 GND 선을 꽂은 레일이야. 위치가 아니라 내 브레드보드에 찍힌 색과 기호로 확인해. 제품에 따라 a줄 바로 옆이 + 레일인 경우도 있는데, 거기 꽂으면 RC522에 4V가 넘게 걸려. a줄 바로 옆이 − 레일이면 사이가 좁으니 한쪽 다리를 U자로 접어 세워서 꽂아. − 레일은 가로로 전부 이어져 있어서 근처 아무 구멍에 꽂아도 같은 GND야.
  • ⑤ 모듈(RC522나 HC-06)로 가는 선을 N칸 d줄에 꽂아. 여기가 약 3.33V가 나오는 곳이야.
채널위아래 1 + 아래 2출력핀 HIGH일 때 전류
SCK · MOSI2kΩ2kΩ + 2kΩ5 × 4k / 6k = 3.33V0.8mA
SDA (SS)10kΩ10kΩ + 10kΩ5 × 20k / 30k = 3.33V0.17mA
HC-06 RXD220Ω + 220Ω220Ω × 45 × 880 / 1320 = 3.33V3.8mA

RC522는 2.3V 이상이면 HIGH로 읽고 최대 3.8V까지 버티니까 3.33V는 안전한 범위야. 모듈 쪽에서 본 저항이 SCK·MOSI는 약 1.3kΩ(2k와 4k의 병렬)이라 4MHz 신호도 충분히 빨리 따라와.

위·아래를 바꾸면 안 돼. 위 1개, 아래 2개(직렬)야. 바꾸면 약 1.7V가 돼서 신호를 못 읽어.

멀티미터 확인: 보드 A 메인 스케치를 실행 중이면 SDA(SS) 핀이 평소 HIGH야. 그래서 SDA 채널 N칸과 GND 사이를 재면 3.2~3.5V가 나와야 해. 5V면 아래 저항이 GND 레일에 안 이어진 거고, 0V면 위 저항이 빠진 거야. 1.7V 근처면 위·아래가 바뀐 거야. 4V가 넘으면 아래 저항이 + 레일에 꽂힌 거니까 바로 USB를 뽑아.

전원 끄고 4채널 모두 확인 (추천): SCK·MOSI는 평소 LOW라 위 방법으로는 확인이 안 돼. USB를 뽑고 아두이노 선과 모듈 선을 뺀 상태에서 멀티미터 저항 모드로 재 봐. 무한대(OL)가 나오면 아래 저항이 − 레일이 아닌 곳에 꽂힌 거야.

채널N칸 ↔ − 레일P칸 ↔ − 레일
SCK · MOSI≈ 4kΩ≈ 6kΩ
SDA (SS)≈ 20kΩ≈ 30kΩ
HC-06 RXD≈ 880Ω≈ 1.3kΩ

05보드 A 단독 테스트

보드 B 없이 보드 A만 확인하는 순서야. 시리얼 모니터는 항상 9600 baud, 줄 끝은 New Line으로 맞춰. 스케치는 firmware/tests/와 firmware/tools/에 있어.

먼저 라이브러리 설치

Library Manager(Ctrl+Shift+I)에서 LiquidCrystal I2C(Frank de Brabander), Keypad(Mark Stanley, Alexander Brevig), MFRC522(GithubCommunity)를 설치해. xxx.h: No such file or directory 오류는 라이브러리가 없다는 뜻이야. 이름이 비슷한 다른 라이브러리는 안 되니까 작성자 이름을 확인해.

06보드 B 실물 배선

브레드보드 위쪽 레일은 아두이노 5V, 아래쪽 레일은 서보용 외부 5V야. 두 − 레일은 둘 다 GND라 이어져도 되지만, 두 + 레일은 절대 잇지 마.

단계어디서어디로선 색 / 부품메모
택트 버튼은 대각선 두 다리를 써

4핀 버튼은 안쪽에서 두 다리씩 붙어 있어서, 같은 쪽 두 다리를 쓰면 방향에 따라 항상 눌린 상태가 될 수 있어. 브레드보드 가운데 홈을 걸치게 꽂고 대각선 위치(왼쪽 위 27번 ↔ 오른쪽 아래 29번)에 선을 연결하면 방향과 상관없이 동작해.

07보드 A ↔ 보드 B 연결

보드 A보드 B메모
A2 (TX)→D4 (RX)A가 보내는 선
A1 (RX)←D5 (TX)B가 보내는 선
GND—GND공통 GND 필수

5V끼리는 연결하지 않아. 각 보드는 자기 USB로 전원을 받아.
