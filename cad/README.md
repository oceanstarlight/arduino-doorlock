# 도어락 3D 도면

| 파일 | 용도 |
|---|---|
| `print/A_box_body.stl` | **3D 프린터용** 보드 A 박스 본체 (앞판+벽) |
| `print/A_box_cover.stl` | **3D 프린터용** 보드 A 박스 뒷판 (도브테일 홈, Uno·브레드보드 고정) |
| `print/A_rail_bracket.stl` | **3D 프린터용** 문에 붙이는 레일 브래킷 |
| `assembly/doorlock_assembly.step` | **전체 완성 도면** (Fusion 360, FreeCAD 등에서 열기, 부품명·색 포함) |
| `../docs/case3d.html` | 전체 완성 도면 웹 뷰어 (브라우저로 열기, 치수·재단 목록·조립 순서 포함) |
| `doorlock_case.py` | 위 파일을 모두 만드는 CadQuery 스크립트 (치수 수정 후 다시 실행) |

## 출력 (Zortrax M200 Plus, Z-ABS 2)
- 출력 범위 200×200×180에 한 번에 안 들어가서 **부품마다 따로** 출력한다. STL은 이미 출력 방향으로 눕혀 두었다.
- 레이어 0.19mm, 채움 20~30%, 서포트 자동(20°), 라프트 기본값.
- 끼움 공차는 한쪽 0.4mm(Z-ABS 기준)다. 레일이 빡빡하면 `CLR` 값을 올리고 다시 실행한다.

| 부품 | 크기 (출력 방향 X×Y×Z) |
|---|---|
| 박스 본체 | 129 × 185 × 63 |
| 박스 뒷판 | 129 × 185 × 13 |
| 레일 브래킷 | 129 × 191 × 29.4 |

## 구조
```
문 바깥 ← 박스 본체(63) | 뒷판(7) | 브래킷(4) | 문(9) → 문 안쪽 (보드 B, 서보)
```
- 박스는 브래킷의 도브테일 레일 2줄에 **위에서 밀어 넣고**, 아래 받침 턱에서 M3×10 나사 1개로 잠근다.
- 정비: 아래 나사 1개 풀기 → 박스를 위로 빼기 → 뒷판 접시나사 4개 풀기.
- 앞판: PIR(위) → LCD → 키패드(왼쪽 아래) + RFID(오른쪽 아래, 앞판 1.5mm 뒤).
- 뒷판: 풀 브레드보드(왼쪽), Uno A(오른쪽 아래, USB가 바닥 노치로).
